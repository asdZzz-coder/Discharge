# Discharge

機台出料表單：把物料建進「物料資料庫」，用「功能規則」設定每個功能需要哪些料，開機台表單時照工單選功能，就會自動帶出需要的料。

## 功能

### 物料資料庫
- 每項物料有**料號**、**名稱**（必填）、**規格**、**備註**。料號不能重複（不分大小寫）。
- 右邊表單新增、修改；點清單上的物料可以修改，按「新增」會用表單內容新增一項（可以拿現有的改一改再新增）。
- 按住 Ctrl 或 Shift 選好幾項，可以一次刪除。
- **從剪貼簿貼上**：在 Excel 選好範圍按 Ctrl+C 再按這個按鈕。第一列可以是標題（料號 / 品號、名稱 / 品名、規格、備註，順序不拘）；
  沒有標題時依序當成 料號、名稱、規格、備註。料號已經有的會更新（新的是空白就保留原本的）。
- 搜尋料號、名稱、規格、備註，空格分開可以打好幾個關鍵字（例如 `NFB 100A`）。
- **選了哪些功能會帶出這項料**：在物料表單勾選功能、填數量，和在「功能規則」頁設定是同一份資料。清單上的「帶出的功能」欄會列出來。
- 改料號時，規則上的料號一起改；刪物料時，會從規則上移除（刪除前會告訴你有幾條規則用到）。

### 功能規則
- 一條規則就是一個**功能**加上它**帶出的料和數量**。可以自行新增、修改、刪除，條數沒有上限。
- 功能名稱必填、不能重複，也不能有「、」或「×」（Excel 用這兩個字元分隔）。
- **適用機種**：規則可以設定哪些機種能用（可以好幾個），都不選就是所有機種都能用。點一下已有的機種選或取消；新的機種在下面打名稱按「加入機種」。機種名稱不能有「、」。
- 按「從資料庫選料」多選物料加進規則，數量可以在表格上直接改。
- 按「儲存」（Ctrl+S）才會存。離開這一頁、換到別條規則、關閉程式時，有沒存的變更會先詢問。
- 修改或刪除規則，不會影響已經建好的機台表單。規則改名時，表單上顯示的功能名稱會跟著改，料和數量不變。

### 機台表單
- 每張表單要填**工令**和**機台名稱**（必填），再從下拉選單選**機種**。工令和機台名稱都一樣的會先詢問。
- 機種清單是規則上設過、或其他表單選過的機種。還沒選機種時，工單功能只列出所有機種都能用的規則。
- **工單功能**：多選的下拉選單，只列出這個機種能用的功能，可以搜尋。照工單勾選，就會帶出這個功能需要的料；取消勾選就扣回去。
  - 好幾個功能用到同一項料時，數量相加（例如正逆轉 2 個、斷路保護 1 個，表單上是 3 個），「來源功能」欄會列出是哪些功能帶的。
  - 取消功能時，只扣掉這個功能帶出來的數量，扣完沒有了才移除那一項；手動多加的數量會留著。
  - 規則後來改了，已經選的功能不會變；想用新的規則，把功能取消再選一次。
  - 規則刪掉後，當初選過的表單上會顯示「（規則已刪除）」；換了機種後已選但不適用的會顯示「（這個機種不適用）」。兩種都可以取消，取消後就不再列出。
  - 規則上的料號資料庫沒有時不會帶出，狀態列會列出是哪些料號。
- **另外選料**：規則帶不出來的料從這裡加。開出物料清單，勾選要出的料（可以多選），數量可以直接改（改了數量會自動勾選）。
  - 換搜尋條件時已經勾的會留著，可以分好幾次搜尋、勾選；「勾選篩選出來的全部」「只看已勾選」。
  - 選取好幾列後按空白鍵，可以一次勾選或取消。
  - 已經在表單上的料會標「已在表單」，再加一次會把數量加上去。
- 表單上每項料可以改數量、寫備註；選取後按「移除選取的料」移除。
- 按「儲存」（Ctrl+S）才會存。換到別台、關閉程式時有沒存的變更會先詢問。
- 左邊清單可以搜尋工令、機台名稱、機種、選的功能，或表單上的料號、名稱、規格。
- 帶料時會把料號、名稱、規格複製到表單上，之後資料庫修改或刪除物料，已經建好的表單不會跟著變。

### 匯出 / 匯入 Excel

標題列右邊的「匯出」「匯入」。匯出的檔案有四張工作表：

- **物料資料庫**：料號、名稱、規格、備註。
- **機台**：工令、機台名稱、建立時間、最後儲存、功能（用「、」分隔）、機種。
- **出料明細**：工令、機台名稱、料號、名稱、規格、數量、備註、來源功能（例如 `正逆轉×2、斷路保護×1`），用工令和機台名稱對應回表單。
- **功能規則**：功能、料號、數量、適用機種（用「、」分隔），一列一項料。可以直接在 Excel 整理好規則再匯入。

匯入時依第一列的標題找欄位，順序可以調換。不是這個程式匯出的檔案，只要第一張工作表的第一列有「料號 / 品號」，也可以當成物料清單匯入。

- **合併**：料號相同的物料用檔案的內容更新（檔案是空白的欄位保留原本的）；工令和機台名稱相同的表單、功能名稱相同的規則，內容以檔案為準；檔案裡沒有的資料保留。
- **完全以 Excel 為準**：檔案有的工作表，內容整份換掉，檔案裡沒有的物料、機台或規則會被刪除。檔案沒有的工作表，對應的資料不動。
- 有讀不懂的列（例如數量不是數字、只填了工令沒填機台名稱）會列出是第幾列，整份都不匯入，改好再匯入一次。
- 匯入前會自動備份目前的資料到 `%AppData%\Discharge\data.before-import-日期-時間.json`。
- 工令和機台名稱都相同的表單，匯出再匯入時會併成一張，相同料號的數量相加。

資料存在 `%AppData%\Discharge\data.json`，是一般的 JSON 檔，可以直接備份。

## 安裝

1. 到 [Releases](https://github.com/asdZzz-coder/Discharge/releases) 下載最新的 `Discharge-ClickOnce.zip`。
2. 解壓縮整個 zip。
3. 執行 `安裝.cmd`。

也可以從「APP 啟動器」下載、開啟；這種情況由啟動器負責更新，程式內的「檢查更新」只會告訴你有沒有新版。

## 開發

需要 .NET 10 SDK。

```bash
dotnet build Discharge.slnx
dotnet test Discharge.Tests/Discharge.Tests.csproj
dotnet run --project Discharge
```

測試時可以設定環境變數 `DISCHARGE_DATA_DIR` 改用別的資料夾，就不會動到正式資料。

## 發佈新版本

推送 `v*` 標籤後，GitHub Actions 會依序執行：

1. 跑自動測試。
2. 用 ClickOnce 打包。
3. 把 `Discharge-ClickOnce.zip` 上傳到 GitHub Releases。

```bash
git tag v1.0.0
git push origin v1.0.0
```
